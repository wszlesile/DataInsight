## 保存协议

首次 definition 的 `present(results, parameters)` 只返回已计算产物 `{"charts": ..., "tables": ...}`，宿主保留为待表达候选，不标记为成功。随后 `express` 阶段基于本次计算事实生成完整报告并调用 `compose_analysis_presentation`；宿主保留原图表、表格、参数与查询回执，最终只保存一次。以下是历史源码接口：

```python
result = save_analysis_result(
    analysis_report=analysis_report,
    charts=charts,
    tables=tables,
    analysis_parameters_schema=analysis_parameters_schema,
    analysis_parameters=analysis_parameters,
)
```

- `analysis_report` 是已求值 Markdown，不残留模板表达式。
- `charts` 与 `tables` 不能同时为空；确实没有可视化意义的有限明细或单指标问题可以 tables-only。
- 不传 `output_text` 或 `output_json`。

## 图表

- 使用 `build_chart_result(...)`、`build_multi_metric_chart_result(...)` 或 `build_chart_suite(...)` 构造 `bar/line/pie/scatter/boxplot`。
- 单指标图使用 `build_chart_result`；同一分类下多指标使用 `build_multi_metric_chart_result`；同一指标需要多种视角时使用 `build_chart_suite`。后者返回列表，前两者返回单个图表项。
- 数据先聚合到图表唯一粒度；同一类别和序列不能重复。多指标用独立数值列，不用混合 value 列承载不同单位和口径。
- 标题和描述写清对象、时间、指标和展示范围。TopN、抽样、采样或降采样必须披露范围。
- 空图表不进入结果。图表报错时保留正确查询和口径，只修粒度、字段映射或 helper 参数。
- 用户要求精度时显式传 `value_precision=N`，报告、图表和表格一致。
- 图表 helper 的 `value_precision` 默认 2，支持 0 到 10 的整数，控制图表数据的数值舍入，不保证用字符串补齐末尾的 0；报告格式化与图表使用同一精度变量。
- 多个业务上彼此独立的数据源默认分别分析、一源一图；不能仅因字段结构或时间范围相同就合成同图。用户要求对比、关联或叠加，或同一对象的多指标、多序列时，可根据实际语义合并展示。这一规则不限定于时序数据源。
- Helper 返回的是可直接放入 `charts` 的完整图表项：`build_chart_suite` 返回列表，另外两个返回单项。对于 helper 已覆盖的图表类型，不要提取、手写或修改 `chart_spec`；后端会从 `chart_document` 编译前端结构。只有 helper 确实无法表达的图表类型，才使用原始 `chart_spec`，仍需满足图表数据、展示和结果保存契约。
- 趋势、对比、分布、排名、占比和时间序列默认应生成有职责的图表；有限明细、单值统计或没有可视化意义的结果可以 tables-only。不能为了满足数量要求生成无数据状态图或失败原因图。
- 同一分类下多个业务指标使用 `build_multi_metric_chart_result`；围绕同一指标生成多视角时使用 `build_chart_suite`。后者每次只有一个 `value_field`，不能借此漏掉其他用户要求指标。
- 饼图只用于金额、数量、时长等可加总构成，毛利率、处理率、平均成本等比率/均值不能作为“份额”相加。
- 明细主键、ID、序号和编码不能直接作为 `value_field`。数量图先按业务维度聚合出明确 count 列；时间分布先派生日期/月并计数。
- 未传 `series_field` 时每个 category 只能一行；传入后每个 `(category, series)` 组合只能一行。重复时按当前业务口径聚合或补充真实系列，禁止 `drop_duplicates`、取首尾行或覆盖静默丢数据。
- 多指标长表若让一个 `value` 列混装不同单位/算法，不形成可比较图表；改成每个指标独立数值列，或分别制图。
- Boxplot 用于分布、异常值和五数摘要；原始明细传 category/value，已汇总数据使用明确的 min/Q1/median/Q3/max 字段。不要为箱线图退回手写前端 option。

## 表格

- 使用 `build_table_result(...)`；返回值直接放入 `tables`，没有 `.table` 属性。
- `columns[*].key` 对应真实字段，`label` 是用户可读业务名，不使用底层编码、临时变量或 `Metric`。
- 每个业务指标使用独立数值列，维度使用独立维度列；同一数值列不能跨行混装金额、数量和比率。
- 空表不进入结果。有限明细说明展示范围，总体结论仍基于完整统计口径。
- `data` 可传 DataFrame 或 records，不能与 `rows` 同时传入。Helper 返回字典包装，直接加入 `tables`，没有 `.table` 属性。
- 报告内嵌 Markdown 表格优先用 `build_markdown_table(...)`；需要业务表头时 `columns` 使用 `{"key":"真实字段","label":"业务名称"}`。
- 表格排序先使用原始时间/数值/等级键，再生成展示文本；不要按格式化金额、百分比或月份文本错误排序。

## 报告

- 报告只使用文本 Markdown；不要输出 Markdown 图片语法、`chart:` 图片 URI 或外部图片链接。图表和表格必须作为结构化 `charts` / `tables` 产物提交，由界面独立渲染；需要在正文定位图表时使用普通文字标题，不伪造图片产物。
- 输出已求值 Markdown。章节由问题和真实发现决定，不写空章节，不展示删除线草稿。
- 核心结论可以是事实型发现：总体数量、完整分布、最大项及并列、可比数值变化本身就是结论，不需要再转成运营评价。开放式问题仍应覆盖用户要求的各维度，并解释字段和指标在 Schema 中已有的业务含义。
- `expression_scope.judgment_scope=descriptive_only` 时，事实型发现和数学比较足以构成完整分析；不要为了写“业务含义”而推断运营健康、流程完整、风险、适用性、原因或行动价值。只有用户明确要求对应判定，或当前计划中存在有来源的判据并由本轮计算支持时，才表达该业务评价；否则说明数据边界。
- 每个重要事实或评价都要给出对应数值、比较范围和必要单位；事实观察是有效结论，不需要补写更强的业务判断。避免只列指标名和数字，也避免把数字包装成未获依据的评价。
- 三类产物复用同一计算变量和总体。百分比明确是比例、百分点差还是相对增幅；单位和精度一致。
- 对外使用 `datasource_name` 或业务对象名，不展示内部 ID、变量名、Helper、SQL 实现和 Runtime 协议。
- 维度只有编码而无法取得名称时，应明确标为“编码/ID”，不能编造名称或把编码冒充业务名称；这不允许把系统内部 datasource_id 等定位编号当成业务说明。
- 开放式问题应覆盖用户要求的总体、趋势/结构/差异等事实分析；Schema 已定义的字段、指标含义可以解释，业务评价与建议取决于用户要求和现有判据，不作为固定章节。窄问题按价值收敛，但不能只回一个孤立数字。
- “最高、并列、增加、减少”等数学关系由完整数据的排序、差值或变化率支持。若“集中、异常、改善、恶化、健康、充足”等词表达业务评价，还必须有实际业务判据；占比、排名和数值变化本身不提供这些判据。
- 报告中的动态判断句由实际计算结果和条件分支决定，不使用固定指标话术套写不同数据状态。
- 占比和括号内数量成对出现时，两者描述同一筛选群体并复用同一分子。百分比需区分比例、百分点差和相对增幅。
- 同比、环比和基期比较使用可比窗口。当前周期未结束时，基期对齐同一月日或同一已完成周期；全年基期只能作为不可直接比较的背景值。
- 同名金额、数量和状态先核对 Schema 中统计对象、业务时点和口径。签约额、合同金额、回款额、预算额等不能静默替代彼此。
- 建议只对应已计算的集中、缺口、变化、异常或覆盖不足。数据不足以判断原因或行动方向时，明确边界，不用通用经营话术填满章节。
- 代码中的条件判断只把实际命中的结论写入报告，不能把“若 A/若 B/若 C”的待判断规则原样展示。
- 报告不出现空章节、删除线草稿、未求值占位、内部数据源编号、字段变量、`query_key/query_constraints/DataFrame/chart_document` 等技术词。
- 使用 TopN、LIMIT、抽样、采样、降采样、head/tail 等减少展示范围时，在对应图表或表格标题/描述中披露实际范围；正文结论也基于不完整样本时，再说明对判断的影响。
- 图表、表格和报告必须复用同一计算变量、总体、筛选、时间和粒度。某个子路径为空时保留其他成功路径，并说明缺失阻断了哪些结论。
