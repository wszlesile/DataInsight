# Runtime 结果驱动表达

## 目标与边界

当前计算函数即使返回正确状态，生成代码仍可能漏掉相等、并列、空集等分支，或者在
叙述中另写一套判断。本次最小增量把数学状态选择与局部表达填值交给确定性函数，
模型负责各情形的业务文字，正式 Python 仍负责完整查询、计算、报告、图表和表格。

这不是新的语义阶段、指标目录、固定报告模板或执行后 Review。不向模型发送执行后的
报告或明细，不要求本地检查源码必须出现某个 helper。Preparation、Probe、同轮次澄清、
外部 text/JSON、本地重跑和任务的流程不变。

**不能保证的部分**：模型是否选择使用函数、统计总体/算法是否正确、表达是否具有实际
业务依据。函数可以选对 greater，却无法认证调用者填入的“健康”文字。不得据此宣称
已解决整体语义准确性，缺少依据的业务评价仍属于待验收问题。

## 接口

| 函数 | 输入 | 互斥情形 | 返回 |
| --- | --- | --- | --- |
| render_numeric_comparison | 两个已计算有限数值、四段表达、可选对象名称 | less/equal/greater/missing | 按真实关系选中的一段已填值字符串 |
| render_extrema | 已计算 DataFrame、数值列、对象名称列、五段表达 | empty/single/unique/tied/all_equal | 保留全部命中对象的一段已填值字符串 |

表达是普通字符串，使用命名占位符和 Python 数值格式，不是先求值的 f-string 或回调。
比较可使用 left/right/difference/relative_change/left_label/right_label；极值可使用
labels/value/valid_count/missing_count/matched_count。名称连接符、单位、语言与表达由调用者
提供。relative_change 为比例，`.1%` 用于百分比展示，不等于百分点差。

每个情形都是必填的非空字符串。接口只检查格式字段和调用完整性，不检查业务词语、
不证明阈值合理。只对选中情形格式化；不可计算值用调用者的 unavailable 文本表示
（默认 N/A），不会填零。NaN 是缺失，Inf、字符串和布尔数值不被隐式解释为有效数值。
精度按调用者算法显式处理。极值计数是可比较行数，不自动推断实体数。

## Evidence 承接

正式代码不生成 Evidence 元数据。后置编译器识别这两个已知函数的字面量表达，展开为
对应的数学表达式和格式槽，继续通过原 QuerySnapshot 与计算依赖生成 Evidence。
差额与相对变化使用不同计算边界；对象标签不被当成指标。未匹配的情形不能用局部文字
兜底去绑定另一分支或截取小数前缀。普通 f-string 的原有处理路径不改变。

动态模板或动态极值模式不做猜测展开，仍由现有后置能力处理；本地解析不了不是已经
证明矛盾。这是有界 API 支持，不是任意 Python 语法穷尽或完全取消 Evidence 的 LLM。

## 落地与验收

1. 实现两类局部表达函数，验证等于、零基期、缺失、空集、单对象、唯一、部分并列、全体相等。
2. 验证格式字段、不可计算值、数据不变性与不同语言表达；证明接口不虚假认证业务文字。
3. 验证文件与关系型查询的 Evidence：准确位置、独立公式、无重叠引用、未选分支不引用。
4. 接入执行命名空间与实际签名参考，仅在实现/修复资料中提供，不给语义规划增加字段。
5. 本地真实复跑 226 空间 15 会话 45/轮次 65；检查模型实际采用、报告深度、数值、判断、
   Evidence、重试及分阶段耗时。成功执行和 complete 均不是整体通过。

真实复跑未通过前不宣称优于已提交版本、不部署、不提交。若模型未采用或报告表达退化，
记录真实原因，不增加 helper-name 门控、业务正则或执行后 Review 来制造通过。

### 对照有效性复核与能力包收敛

Probe 形态识别、结果收口归一化及静态代码契约检查。直接 Worker success 不是
正式提交成功；完整 Runtime 的上下文、权限及执行状态验证仍不在此隔离测试内。

历史测试补查结果：38.5 秒的程序通过正式静态检查，但语义不通过；10.015 秒的

将 evaluate_numeric_comparison、summarize_extrema、render_numeric_comparison、
render_extrema 的说明与示例收纳到 execution.numeric_interpretation 可选能力包。

也不改变 Probe、澄清、外部结果协议或后置 Evidence 的职责。

用更新后的真实契约再次隔离生成，43.157 秒，通过静态提交检查并执行成功，

实现错误的局部观察，不能认定为稳态改善或语义验收通过。相关两组测试分别
300、298 项通过（存在重叠，不能相加为独立测试总数）。

当前剩余承接问题分为两个不同边界：完整计算结果与派生极值/展示集合的用途
没有稳定保留；正文与建议仍脱离已定义的结果依赖重新作业务解释。下一轮设计
必须对这两个边界分别验证，而不是把更多 Helper、静态业务检测或后置 Review
当作正确性的替代方案。未提交、不更新远端、未回写历史结果。

### 结果用途协议试验与撤回

尝试在现有计算定义加入完整结果/选择子集的覆盖属性，在判断定义加入比较总体
引用，由本地索引连接两者；没有增加阶段、业务阈值或语义检测门控。隔离实现
46 秒首次生成后因无效的条件格式化表达失败；同上下文一次修复耗时 36.25 秒，
解决格式错误，但又因图表数据重命名后 category_field 未同步而失败。因此首次
实现稳定性未通过，不能计为完整分析成功。

保持同一份修复后程序不变，本地替换文件读取返回的数据，执行全体相等、部分
并列、唯一最大、单组、空集五个变体。未调用模型，未发送数据、正文，未写入
洞察数据库。保存入口只旁路记录生成正文，仍调用原保存函数与原图表验证器；
前四个变体均保留 chart_contract_error，空集保留 no_data_found。正文捕获仅用于
定位，不能当作正式执行通过或无数据建议报告通过。

源码及正文确认：极值解释函数只接受极值子集，无法区分全体相等与部分并列；
唯一最大被描述为“唯一制造商”，但完整结果仍有十家；位置说明另外取第一行，
将并列结果写成该位置最高；单组变体仍出现“一家制造商说明渠道分散”的静态
推断。业务建议没有因真实结果改变而相应改变。空集能产生信号，但完整无数据
交付不在本次隔离验证范围内。

结论：新增用途属性未稳定成为实现行为，不能据此认为准确性已改善。已撤回
本轮 result_extent/subset_definition/comparison_fact_ids 的模型、索引、提示词和
测试改动，不保留未验证的协议扩张；此前数值解释可选能力包及既有功能保留。
撤回后相关 277 项测试通过。工作目录保存隔离请求、程序、变体输入的独立统计
与正文捕获，用于下一次设计对照，不加入业务代码。

该试验进一步限定问题：结果身份说明并不能替代实际的数学情形判定，正确的
比较算法也不能保证正文没有绕过它的第二套解释。后续应在现有流程内验证确定
性计算结果如何统一驱动解释，而不是继续扩大计划对象、重复写更细的自然语言
要求，或以更多整份代码修复掩盖这一缺口。

### 默认数学事实表达及证据兼容验证

将已有 render_extrema 简化为可直接接收完整比较结果的事实表达函数。未指定模板
时，本地处理空集、单项、唯一极值、部分并列、全体相等及缺失值，不推断集中度、
健康或业务风险。调用方仍可覆盖模板；这种覆盖不代表业务解释已经得到认证。
比较项是输入行，不自动等同于去重后的业务实体。复杂比较模板仍为可选能力包。

真实模型在隔离实现请求中采用该调用，38.484 秒首次生成，通过正式静态代码
检查并本地执行成功。完整制造商/位置分布被正确描述为十项各一台，安装年份
2022、2023 被正确描述为并列。此耗时不包含 Preparation、语义规划或 Evidence，
不能作为简单会话总耗时达标的证明，也不能证明多次模型调用的稳态正确性。

同一程序本地执行全体相等、部分并列、唯一最大、单项四个数据变体均成功，
数学表达与独立统计一致；空集触发 no_data_found，未认证最终无数据建议报告。
但单项数据仍附加“不同类型存在差异”，安装分布仍被解释为产能扩张，供应商
建议仍为静态判断。默认数学表达只能消除其自身范围内的错误，不能保证整份
报告的语义正确性，不能据此认证该会话通过。

Evidence 编译器与函数共享可信默认模板，不执行生成代码，保留项数与极值的
独立计算签名及查询来源。中英文、缺失值及自定义模板相关组合测试共 607 项
通过。实际程序不调用 Evidence 模型的本地编译耗时 1.656 秒，生成 25 个定义、
16 个报告引用、7 个图表引用及 12 个表格引用；19 个结构化数值槽全部绑定。
报告仍有三个未分类候选，状态为 partial，不能宣称完整覆盖或兜底已通过。

后续收敛必须区分数学事实与业务推断：前者可由确定性函数完整表达，后者必须
具有明确的语义依据和结果依赖。不能靠替换全部报告文字、业务关键词门控或
后置 Review 掩盖静态推断；也不能继续增加用途属性而未验证程序是否实际采用。
本轮没有新增阶段、变更选源/Probe/澄清职责、更新远端部署或回写历史记录。
