# Runtime 工作连贯性与分析进展展示

## 需求与边界

2026-09-09讨论稿。先设计与复核，不随正在进行的回归部署前端改动。

目标一：模型每次工作能理解当前目标、已有观察及来源、当前有效判断、未解决依赖，以及本次工作的原因。
目标二：用户能看到分析计划、已执行动作、观察摘要、调整原因和完成状态，而不是长时间只看到大阶段标题。

展示的是简洁、可核对的工作说明，不直接展示模型内部推理文本，不编造没有发生的工作。
不要求额外LLM总结每次工具调用，不把前端说明再次写回模型历史形成重复上下文。

## 当前代码事实

- runtime_working_context保留原始轨迹，按版本和工作状态生成发送视图；最近Probe的动作与结果应成对保留。
- assistant分析说明当前主要保留原文；没有完整的判断替代关系管理，因此保留历史不能等同业务认识连贯。
- invoker使用updates/custom流，展示部分assistant说明和工具调用；内部结构化反馈通常被过滤。
- _format_tool_call_message只针对执行、Probe和协议读取提供文案，工作选择、材料计划及Schema读取落入内部工具名默认提示。
- 本次43/63真实请求已验证：完成的Probe调用与观察保留，后接模型工作选择；这只证明该轨迹动作连贯，不证明全部分析判断正确。
- 当前状态只能证明执行事实。例如Probe成功不证明业务口径已确定，材料覆盖不证明没有新依赖。

## 建议方案

共用真实工作事件来源，分开两种投递视图：

| 内容 | 模型视图 | 用户视图 |
| --- | --- | --- |
| 工作目标与范围 | 原问题、用户补充、当前焦点，保留完整目标 | 简短业务目标与本次工作说明 |
| 执行动作 | 调用ID、参数、结果、当前代码版本 | 数据读取、探测、生成、执行、修复等进度 |
| 观察 | 查询/工具来源、范围、已确认事实和限制 | 安全的观察摘要，不展示原始样本或凭证 |
| 分析判断 | 模型生成的简短判断摘要、依据、待确认项与修订关系 | 有必要解释时展示简短调整原因，不输出原始内部推理 |
| 下一步 | 与已确认观察一致的工作意图；本地维护可用能力 | 准备做什么，不把计划表述成已完成 |

本地维护执行事实、版本、消息配对、恢复和权限。LLM负责业务判断与后续意图；
不允许模型自行更改执行成功状态，也不让本地根据工具成功推断业务判断成立。

## 最小落地顺序

1. 先验证现有请求视图的事件连续性，补足Probe、修复、补读、澄清恢复的联合测试。
2. 审计现有事件存储和前端消费，确定可复用的事件ID、顺序、重连游标与持久化路径。
3. 从现有确定性工具事件生成更细的用户进展，复用现有SSE传输，不额外请求LLM。
4. 模型的简短工作说明在现有交互中产生，明确它是说明/判断而非执行事实。
5. 判断摘要的更新方式先验证兼容性，再决定是否增加结构化字段；不要直接扩张材料计划或引入强制新Stage。

## 验收

- Probe后进入实现，模型可定位已完成观察和来源，不重复执行已完成工作来找回信息。
- 修复看到当前代码与对应错误，仍保留用户完整目标和有效观察。
- 用户能看到真实进展，耗时期间不使用虚假的百分比或伪造“正在思考”的内容。
- 工具开始、成功、失败和重试可区分；同一事件不重复展示，重连后顺序一致。
- 切换会话、刷新、澄清挂起/恢复、终止均不串消息；兼容外部分析禁用澄清的模式。
- 不向前端发送凭证、未授权数据、完整内部提示词或原始内部推理。
- 不为每条进展增加LLM调用，不改变正式代码、Probe、no-data、Evidence和本地执行能力。

## 当前落地状态

- `work_progress` 由 Runtime 工作状态、模型调用生命周期和真实工具生命周期生成，不增加额外模型调用。
- 后台在广播 SSE 前持久化公开事件；历史和轮次详情接口返回当前分析任务版本的 `progress`。
- 前端按 `activity_id` 合并 running/terminal 事件，刷新或切换会话后恢复已持久化进展。
- 带工具调用的 assistant 自由文本不作为公开分析过程。用户看到的是模型主动提供的安全摘要和真实执行状态，
  不是内部推理、代码或工具脚手架。
- 同轮次澄清继续由 Runtime 在完整语义下判断。只有互斥解释会实质影响计算正确性，且上下文、Schema、
  业务规则与 Probe 都无法消除时才澄清；可接受的合理口径应继续分析并在结果中披露。

以上进展链路已在会话44、45、46真实刷新中验证持久化和终态闭合；Runtime整体稳定性、准确性与
Evidence仍按回归矩阵独立验收，不能因进度展示通过而视为整体验收完成。
